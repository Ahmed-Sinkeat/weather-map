# WeatherMap

A vanilla JavaScript weather map project using Leaflet, OpenStreetMap and OpenWeatherMap.

## Run

Open `index.html` in a browser. No installation is needed for the current page.

## Day 1

1. Page structure: heading, labeled location input, disabled search button and map placeholder. Complete.
2. Styling: separate CSS, typography, responsive layout and a map container sized to `70vh`. Complete.
3. Map setup: separate JavaScript and Leaflet with OpenStreetMap. Pending.

Search is disabled until weather integration is implemented. Day 2 and Day 3 have not started.
